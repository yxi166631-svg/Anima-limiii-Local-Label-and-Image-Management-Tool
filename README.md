ANIMA本地标签和图像管理工具 介绍与使用说明
ANIMA本地标签和图像管理工具 是一款用于浏览、整理和管理 AI 绘图 Tag 的本地工具。它整合了 D 站浏览、本地图片与 TXT Tag 整理、收藏、翻译、反推、批量处理等功能。程序与个人数据分离。
主要功能
- D 站浏览
  - 支持搜索图片、Tag、角色、画师与排行榜。
  - 排行榜已拆分为日榜、周榜、月榜。
  - 可查看图片大图、复制 Tag、收藏图片、收藏 Tag。
  - 支持在收藏页检索、分类、分组与批量管理收藏内容。
  - 支持从收藏内容汇总“所有 Tag”，自动去重、统计使用次数并按数量排序。
  - 所有标签均可搜索、复制、收藏，或从相关收藏图片中批量删除。
- 标签翻译与查询
  - 支持 D 站 Tag 的中文翻译。
  - 角色查询支持中文名称、英文名称与常用别名。
  - 画师查询同时显示画师 Tag、唯一 ID 与可见用户名，点击对应内容即可复制。
  - 标签可按人物、角色、版权、画师、通用标签等分类显示。
- 本地 Tag 整理
  - 可添加多个本地图片文件夹，文件夹记录保存在个人数据目录。
  - 自动读取图片及同名 .txt 文件中的 Tag。
  - 支持搜索、筛选、复制、删除与编辑图片 Tag。
  - 可查看大图并快速定位到原始图片所在文件夹。
  - 支持读取本地翻译，并优先显示已有的中文翻译。
  - 文件夹页会显示图片数量、文件夹大小等信息。
  - 图片使用缩略图缓存加载，降低大量图片文件夹的卡顿情况。
- 本地 Tag 批量操作
  - 支持全选图片。
  - 支持批量添加 Tag，可选择添加到 TXT 的开头或结尾。
  - 支持批量删除 Tag。
  - 支持清除图片元数据，可选择直接覆盖原文件或另存处理后的文件。
  - “所有 Tag”可统计当前文件夹的全部 Tag，去重后显示出现次数，并可同步修改所有对应 TXT 文件。
- 反推功能
  - 支持在线 Tag 反推、本地 Tag 模型反推与自然语言反推。
  - 本地模型可从个人数据目录中读取和切换。
  - 自然语言反推支持填写接口地址、API Key、模型名称等配置。
  - 可对指定本地文件夹进行批量反推，自动生成同名 TXT 文件。
  - 已存在 TXT 时会提示选择是否替换，避免误覆盖已有 Tag。
- 收藏与提示词
  - 支持收藏本地图片、D 站图片与 D 站 Tag。
  - 收藏 Tag 可自主添加、修改、删除，并可一键用于 D 站搜索。
  - 提示词支持保存、下拉切换和替换，便于管理常用内容。
使用说明
1. 双击ANIMA.bat或 ANIMA.exe 启动程序。
2. 首次启动时，程序会在主程序同级目录自动创建 ANIMA-个人数据 文件夹。
3. 收藏、设置、API 配置、Token、本地文件夹记录、缩略图缓存和模型等个人内容都会保存在该目录中。
4. 使用“本地 Tag 整理”时，先添加图片文件夹；程序会读取其中的图片与同名 TXT Tag 文件。
5. 使用在线反推或翻译功能前，按需在设置页面填写对应 API 或 Hugging Face Token。
